# Скрипт для анализа покерных сессий на PokerOK

**PokerCraft Session Analyzer** `sessionanalyzer.py` — это Python-скрипт для анализа выгрузок PokerCraft из покер-рума PokerOK (GGNetwork). Он позволяет игрокам анализировать свои кэш-сессии или турниры (MTT): рассчитывать винрейт (bb/100), EV bb/100, рейк, графики прибыли, результаты по позициям, лимитам и динамику по времени. 

> Проект создан как открытый инструмент для профессиональных и полупрофессиональных игроков, желающих контролировать и улучшать свои результаты без сложных трекеров.

---

## 🚀 Возможности

✅ Поддержка CSV и JSON выгрузок PokerCraft  
✅ Автоматическое определение лимитов (`0.5/1`, `1/2` и т.д.)  
✅ Пересчет результатов в больших блайндах (`--bb-normalize`)  
✅ Отчеты по позициям и лимитам  
✅ Кумулятивный график прибыли (`--plot`)  
✅ Фильтрация по дате, позиции и лимиту  
✅ Поддержка таймзон (`--tz Europe/Madrid`)  
✅ Удобный CLI-интерфейс  
✅ Подробный лог в консоль  
✅ MIT лицензия — можно свободно использовать и дорабатывать

## ⚙️ Пример использования

### Анализ кеш-игры за месяц:

```bash
python sessionanalyzer.py \
  --input pokercraft_sept.csv \
  --game cash \
  --bb-normalize \
  --start 2025-09-01 \
  --end 2025-09-30 \
  --tz Europe/Madrid \
  --report summary,positions,stakes,timeline \
  --plot \
  --out sept_report.md \
  --img-out charts/
```

### Анализ нескольких лимитов:

```bash
python sessionanalyzer.py \
  --input hands.csv \
  --bb-normalize \
  --stakes-filter "0.5/1,1/2" \
  --report summary,stakes
```

### Проверка структуры файла:

```bash
python sessionanalyzer.py --input dump.csv --dry-run
```

## 🧩 Основные аргументы CLI

| Аргумент           | Описание                                                     |
| ------------------ | ------------------------------------------------------------ |
| `--input`          | Путь к файлу CSV/JSON PokerCraft                             |
| `--game`           | Тип игры: `cash` или `mtt`                                   |
| `--currency`       | Валюта выгрузки (если отсутствует в файле)                   |
| `--stakes-filter`  | Фильтр по лимитам (например, `0.5/1,1/2`)                    |
| `--positions`      | Список позиций для анализа (например, `SB,BB,CO,BTN`)        |
| `--start`, `--end` | Дата диапазона (`YYYY-MM-DD`)                                |
| `--tz`             | Таймзона для парсинга и отчетов                              |
| `--bb-normalize`   | Пересчитать результаты в BB                                  |
| `--report`         | Секции отчета (summary, positions, stakes, stacks, timeline) |
| `--plot`           | Построить PNG-графики                                        |
| `--out`            | Сохранить Markdown-отчет                                     |
| `--img-out`        | Папка для изображений                                        |
| `--dry-run`        | Только парсинг, без расчетов                                 |
| `--verbose`        | Подробный лог                                                |

## 📊 Что считает скрипт

### 📈 Основные метрики:

* Количество раздач
* Общий профит (`Net`)
* Рейк
* `bb/100` — винрейт на 100 раздач
* `EV bb/100` — винрейт по ожидаемой стоимости (если есть поле `allin_ev_diff`)
* Кумулятивная прибыль во времени
* Таблицы по позициям и лимитам

### 📅 Временной анализ:

* Группировка по дням, неделям или часам (опционально)
* Кумулятивный график прибыли
